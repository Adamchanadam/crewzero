# 你今次嘅工作：按文件預填「告訴 Zero」頁的八條問題

創辦人喺 CrewZero 「告訴 Zero」頁加入咗文件，想你按文件預填八條問題。同一個資料夾：

- `files/`：創辦人加入嘅文件（只可以讀）。
- `questions.json`：八條題目（`id`、問題、提示）。
- `files.md`：逐份列出 `files/` 入面嘅檔名，直接按檔名讀，唔使列資料夾。

讀附件嘅方法：PDF 收件時已轉成文字版（同名 `.md`），先讀文字版；冇文字版先用讀檔工具**一次過讀整份**，唔好用 `pages` 參數分頁讀（分頁讀要電腦另外裝軟件，會報錯）；整份讀失敗先改用其他方法。Word、PowerPoint、Excel 檔（.docx、.pptx、.xlsx）收件時已轉成文字版：`files.md` 會喺該附件下一行寫明文字版檔名，同名 `.md` 就係文字版，讀文字版即可；圖片、圖表同版面唔喺文字版入面。文字版轉唔出嘅附件（舊格式、有密碼、太大、損壞、冇內容）先當讀唔到：唔好扮讀過，亦唔好按檔名推斷內容；`files/` 入面同名嘅 `.md` 可以逐字核對原句，`source` 寫原附件檔名（唔係 `.md` 文字版）。每個讀唔到嘅檔案（包括試過其他方法仍然讀失敗嘅 PDF）都要寫入 `out/prefill.json` 嘅 `unreadable` 清單：`file` 只寫檔名本身（例如 `計劃書.docx`），唔好加 `files/` 或其他路徑；`reason` 用書面語寫一句原因（例如「Word 檔案目前無法讀取」，只供紀錄，唔會直接顯示畀創辦人，亦唔好寫工具名稱或參數名）；外殼會逐份用固定字句告訴創辦人，並按檔案類型給建議（Word、PowerPoint、Excel：請另存為 PDF 再交，或在「告訴 Zero」頁直接寫下文件重點；PDF：請確認文字不是只在掃描圖片內，或重新另存後再交；其他格式：請改交 PDF，或直接寫下文件重點）；你只需要列出檔名，唔使寫建議。讀唔到唔等於「文件冇講」：只靠讀唔到嘅檔案就答唔到嘅題，`text` 留空，唔好喺 `text` 寫解釋或者「文件冇資料」。

你只做一件事：讀文件，逐條預填。**唔好擬公司概覽，唔好建任何問題包，唔好寫其他產出。**

## 規矩（一定要守）

0. 文件如係 CrewZero 範本（每題有「你的答案：」）：照抄該題「你的答案：」之後嘅文字，`quote` 寫 `true`，`source` 寫檔名，`at` 寫題號；空白嘅題 `text` 留空。範本入面嘅提示同例子唔係答案，唔好抄。

1. 只可以讀寫呢個資料夾；只寫 `out/prefill.json`。
2. **原句優先**：文件有直接講到嘅，照抄文件原句（可以抄一至三句，一字不改，包括標點），`quote` 寫 `true`，`source` 寫檔名，`at` 寫喺文件邊一節（標題或者頁數）。
3. 文件冇原句、要你歸納或者推斷先答得到嘅，用一兩句書面語寫，`quote` 寫 `false`，`source` 寫主要根據嘅檔名。**唔可以將你寫嘅句子標成原句。** 外殼會逐字喺文件核對，核對唔到嘅會改為「Zero 按文件推斷」。
4. 讀得到嘅文件完全冇講嘅題，`text` 留空，唔好估。
5. 第 5 題（目前進展）只寫公司以外已經發生嘅事；文件冇講已發生就留空。
6. 唔好寫文件冇嘅人名、數字、日期或者承諾。
7. **按今日日期判斷**：工作說明第一行有今日日期。文件寫「本週」「今日」「下星期」或者某個日子，先對照文件日期同今日日期；已經過咗嘅事唔好寫成仲未發生（例如「本週安排三場會議」而三場都已過，就寫「三場會議日期已過，文件未有結果」，`quote` 寫 `false`）。照抄原句時亦一樣：原句講嘅時間已過，就改用按文件推斷。

## 要交

`out/prefill.json`（只可以係有效 JSON）：

```json
{
  "answers": {
    "q1": { "text": "文件原句或者你寫嘅一兩句", "quote": true, "source": "檔名.md", "at": "邊一節" },
    "q2": { "text": "", "quote": false, "source": "", "at": "" },
    "q3": { "text": "", "quote": false, "source": "", "at": "" },
    "q4": { "text": "", "quote": false, "source": "", "at": "" },
    "q5": { "text": "", "quote": false, "source": "", "at": "" },
    "q6": { "text": "", "quote": false, "source": "", "at": "" },
    "q7": { "text": "", "quote": false, "source": "", "at": "" },
    "q8": { "text": "", "quote": false, "source": "", "at": "" }
  }
}
```

`q1` 至 `q8` 每條都要有；冇資料嘅 `text` 留空。`unreadable` 只列讀唔到嘅檔案（`file` 只寫檔名，唔加 `files/`，一定要係今次交入嘅檔名，唔可以編造）；全部都讀得到就寫 `[]` 或者唔寫。例如：

```json
"unreadable": [{ "file": "計劃書.docx", "reason": "Word 檔案目前無法讀取" }]
```

做完就停。
