# 你今次的工作：起草延伸功能

創辦人想加入一項自訂資料表功能。請讀取 `request.md` 的要求、現有草稿及 `templates/`（如有），只在 `out/` 交付兩個 JSON 檔。

`out/extension.json` 必須是 `crewzero.extension/1` 宣告，包含名稱、簡介及一至三個資料表。每個資料表有文字標題欄位；欄位可用文字、數字、金額、日期、布林、選項、工序或名單對象。可加入最多四個摘要。不可有 `page`。

修改現有功能時，不可刪除資料表或欄位，不可改變欄位種類，不可刪除或重用現有代號；需要停止使用的工序要保留為退役代號。

`out/sample.json` 是最多五行的示範資料清單，只作預覽。不得對外聯絡、不得建立其他檔案。完成即停。
